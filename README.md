# CustomShortcuts

A native macOS app that lets you create and manage custom keyboard shortcuts to replace existing ones, either system-wide or for specific applications.

## 🎯 Concept

CustomShortcuts allows you to "remap" keyboard shortcuts in real-time. For example, you can transform `Ctrl+C` into `Cmd+C` in a specific application, or create custom system shortcuts that work everywhere on your Mac.

**Use cases:**
- Adapt Windows/Linux shortcuts to macOS
- Harmonize shortcuts for non-native applications
- Create custom shortcuts for productivity
- Replace difficult combinations with ergonomic alternatives

## ✨ Features

- **System shortcuts**: Work in all applications
- **App-specific shortcuts**: Active only in the selected application
- **Intuitive interface**: Real-time recording and visual editing
- **Import/Export**: Save and share your configurations
- **Auto-launch**: Option to start with macOS

## 📋 Requirements

- macOS 11.0 (Big Sur) or later
- Accessibility permissions (requested automatically)

## 🚀 Usage

### Create a system shortcut
1. Select **"All system"** in the sidebar
2. Click **"Add shortcut"**
3. **Name**: Give it a descriptive name
4. **Old shortcut**: Click and type the combination to replace
5. **New shortcut**: Click and type the replacement combination
6. Enable the toggle

### Add an application
1. Click **"+"** next to Applications
2. Select your application
3. Create your app-specific shortcuts

### Import/Export
- **Export**: File Menu → Export shortcuts
- **Import**: File Menu → Import shortcuts
